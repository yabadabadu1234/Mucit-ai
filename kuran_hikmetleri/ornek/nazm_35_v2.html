5. Girintili kod görünümü (açık kaide adları; metin siyah)

cümle-i fiiliyye {
  tekit {
    atıf/istînâf vâvı: وَ   lâm-ı tevkîd: لَ   harf-i tahkik: قَدْ
  }
  fiil {
    lafız: تَرَكْنَا   kök: ت-ر-ك   tür: sülâsî mücerred   bâb: fe'ale-yef'ulu
    zaman: mâzî   şahıs: mütekellim ma'al-gayr   hüküm: mebni
    fâil { zamir-i muttasıl: نَا   i'râb: mahallen merfû }
  }
  taalluk {
    harf-i cer: مِنْ   mecrûr zamir: هَا (mahallen mecrûr)   müteallik olduğu: تَرَكْنَا
  }
  mef'ûlün bih {
    lafız: آيَةً   kök: أ-و-ي / أ-ي-ي (iki görüş)   i'râb: mansûb, alâmeti fetha
    na't {
      lafız: بَيِّنَةً   kök: ب-ي-ن   tür: sıfat-ı müşebbehe   i'râb: mansûb, alâmeti fetha (mevsûfuna tâbi)
    }
  }
  gâye {
    harf-i cer: لِ   mecrûr isim: قَوْمٍ   kök: ق-و-م   i'râb: mecrûr, alâmeti kesre
    sıfat cümlesi (na't, mahallen mecrûr) {
      fiil: يَعْقِلُونَ   kök: ع-ق-ل   bâb: fe'ale-yef'ilu   zaman: muzâri'   şahıs: gâib cem' müzekker   i'râb: merfû, alâmeti nûnun sübûtu
      fâil: و (vâv-ı cemâ'a, zamir-i muttasıl, mahallen merfû)
    }
  }
}

6. Emoji–mana sözlüğü (resimdeki yeri, kök, Türkçe akrabası)

KelimeKökManaResimdeki yeri ve nedenTürkçe akrabası
👊وَلَقَدْ(harf)kesinlik, yeminMasaya inen yumruk: "bu böyledir, tartışma yok". Sert vuruş her kültürde kesinliktir.kad, tekit
🧹تَرَكْنَات-ر-كgeride bırakmakHer şeyi süpürüp yalnız bir şeyi bırakmak. Süpürge "gitti" der, geride kalan "bıraktık" der.terk, tereke
👉مِنْهَا(harf)ondanYıkıntıdan gösteren el: "buradan, şuradan".min
🪙آيَةًأ-و-ي / أ-ي-يişaret, nişaneToprağın altında gömülü hazineden yüzeye vuran sikke: gizli hakikatin zuhuru. Tabela değil, derinin yüzeye çıkan ucu.ayet
✨بَيِّنَةًب-ي-نapaçıkParıltı: göz kamaştıran, gizlenemeyen.beyan, beyyine
👥لِقَوْمٍق-و-مbir toplulukBirden çok çöp adam: grup. Gösteren elin hedefi.kavim
🧠يَعْقِلُونَع-ق-لaklederlerÇöp adamların başında gerçek gibi çizilmiş beyin: düşünen kalabalık.akıl, mâkul
