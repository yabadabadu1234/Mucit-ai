# TÜREME ŞABLONU

```
 S ──(ok)──▶ T        bir türeme = bir ok; silsile = ok zinciri
 her ok: K · L · D · M · Y   (beşi de yazılır, yazılamayan halka ispatsız)
 silsile: önce BİÇİM kolları (L, D) → biçimler bitince MANA kolları (M, Y)
```

## K  KAYNAK
```
 cins : kök | kelime | ses taklidi | yabancı lafız
 sayı : bir | çok (nahit)
```

## L  LAFIZ BAĞI  (harf × sesli × sıra = 18 hâne)
```
 harf \ sesli,sıra   aynı,aynı   fark,aynı   aynı,fark   fark,fark
 eşit                özdeş       vezin       kalb        kalb+vezin
 ilave               salt ilave  ilave+vezin ilave+kalb  hepsi
 hazf                hazf        hazf+vezin  hazf+kalb   hepsi
 karma               ibdâl/nahit +vezin      +kalb       hepsi
 ayrık               —           (sesli aynı/farklı: 2 hâne; sıra yok)

 ilave : eklenen = kopya | zâid | yabancı      yeri = baş | orta | son
 hazf  : yeri = baş | orta | son
 ibdâl : mahrec yakını | değil
```

## D  KAPSAM (hedef daima ism)
```
 hedef  : ism  (müştak isimler + fiil bâblarının masdarları)
 kaynak : kök | ism | fiil bâbı
 masdar: her bâbın (mücerred · mezîd · rubâ'î · mutâvaa · meçhul)
 DIŞARIDA: fiil çekim sîgaları (mâzî · muzâri' · emir · nehy), harf
```

## M  MANA
```
 çekirdek korundu mu?
 ├─ EVET → cephe: özdeş | fâil | mef'ûl | âlet | mekân | zaman | sebep
 │                | netice-hâl | nev'-hey'et | miktar-derece | sayı | merre | …(açık sicil)
 └─ HAYIR → çekirdekler arası:
      tahsîs (T⊂S) | tevessü' (T⊃S) | kısmî örtüşme | ayrık
      ayrık → bayraklar: benzerlik □  bitişiklik □  zıtlık □   (2³=8; üçü boşsa tesadüf)
```

## Y  YERLEŞME
```
 ilk vâzı' (lügavî) | Şâri' (şer'î) | örf-i âmm | örf-i hâs
```

## C  CEM' VE TESNİYE  (ders notları, F 352)
```
 ferd (tek) → tesniye (ikili) (-ân/-eyn)
      → cem'-i sâlim : müzekker -ûn/-în · müennes -ât
      → cem'-i mükesser : ef'âl fu'ûl fi'âl ef'ile fü'al fu'alâ' fu'ât fe'ale
                          mefâ'il mefâ'îl fevâ'il fe'âil efâ'il   (kalıp adı yazılır)
      → cem'u'l-cem' (+ât)
```

## N  CİNSİYET  (ders notları, F 352)
```
 müzekker | müennes
 müennes : hakîkî | semâî | lafzî
 alâmet  : tâ-i merbûta (ـة) | elif-i maksûre (ى) | elif-i memdûde (اء)
 uyum    : sıfat-mevsûf · akıl sahibi olmayan çoğul → müfred müennes
```

## V  VEZİN ADI  (müştak sicili)
```
 fâil fâ'il · mef'ûl maf'ûl · mekân-zaman maf'al/maf'il/maf'ale
 âlet mif'âl/mif'al/mif'ale · sıfat-ı müşebbehe fa'îl/fa'ul/fa'lân
 tafdîl af'al (müennes fu'lâ) · mübalağa fa''âl/fa''âle/fa'ûl/mif'âl
 her kayıt: vezin × tesniye × cem' × cinsiyet
```

## H  İ'RÂB HÂLİ  (tenvinli biçimler, F 354)
```
 ism hâli : merfû' (-un) | mansûb (-an) | mecrûr (-in)
 mansûb masdar : mef'ûl-i mutlak  (tevkîd | nev' | adet) | hâl | mef'ûl sânî | temyîz
 tekrâr : aynı biçim iki kez = ardı ardına, parça parça, tam tamına
 ara adım : kök → bâb → masdar → hâl işareti (tenvin) → cümledeki vazife → tekrâr
 fiil DEĞİL : tenvin ve nasb işareti ismin alâmetidir
```

## B  İSİM BÂBLARI SİCİLİ  (internet taraması, F 355; i'râb hâlleri hariç)
```
 câmid | müştak
 masdar     : sülâsî mücerred semâî vezinler (fa'l fi'l fu'l fa'al fu'ûl fi'âl fu'âl fa'âl fa'âle fu'ûle fi'âle fa'îl fa'lân fa'lâ …)
              mezîd ve rubâ'î bâblar kıyâsî
 masdar-ı mîmî : mef'al (mücerred) · mezîd: ism-i mef'ûl kalıbı
 ism-i merre   : fa'le · mezîd: masdar + tâ
 ism-i hey'et (nev') : fi'le
 masdar-ı sınâî : ism + iyye/iyyet
 ism-i masdar  : fiilin harflerinden eksik, masdar manalı (vudû', kelâm)
 müştak (sekiz) : fâil · mef'ûl · sıfat-ı müşebbehe · mübalağa · tafdîl · zaman · mekân · âlet
 ek    : mensûb · tasğîr · tesniye · cem' (sâlim/mükesser) · müzekker-müennes
 ism-i cins : cem'î (tekili tâ/yâ ile) | ifrâdî
 DIŞARIDA : ism-i fiil, ta'accüb, işâret, mevsûl (câmid/fiil sîgası, kökten türemez)
 kaynak : TDV Sarf; fasiharapca; arabic-for-nerds ism-i masdar; Mehmet Akif tezi s.198–201 (mîmî, merre, hey'et)
 ENGEL (yoklanamadı): ism-i masdar ve ism-i cins için dekk kökünde tanıklı örnek
```

## GEÇERLİK
```
 iştikak = (L ≠ ayrık) ∧ (M ≠ tesadüf)
```

## DAYANAK (ispat öncülleri)
```
 P0  türeme bağı K·L·D·M·Y dışına çıkmaz
 P1  her eksen çelişik ikilem veya küme münasebeti (beş hâl) ile kapalı
 P2  cephe sicili sayımla (istikrâî): tek açık kapı
```

## GÜNCELLEME KAYDI
```
 1  ilk şablon (K L D M Y, geçerlik kaidesi)
 2  mekânî yerleşim; silsile düzeni (önce biçim, sonra mana)
 3  D ekseni daraltıldı: hedef daima ism; fiil çekimleri ve harf dışarıda (F 350)
 4  mutâvaa/meçhul/rubâ'î bâblarının masdarları kapsamda; bütün bâblar ve müştaklar (F 351)
 5  ders notları denetimi: C cem'/tesniye, N cinsiyet, V vezin sicili eklendi; her müştak 4 eksenle (F 352)
 6  her ilavenin Türkçesi yazılır (F 353); kartlarda Türkçe mana eklendi
 7  H ekseni: tenvinli/mansûb masdar, tekrâr, ara adım zinciri (F 354)
 8  B ekseni: isim bâbları sicili (mîmî, merre, hey'et, sınâî, ism-i masdar, ism-i cins) (F 355)
 9  iştikak motoru kuruldu: `turetme_motoru/istikak.py`; Arapça otomatik, Türkçe ve mana elle (F 359)
 10 iştikak motoru: aksâm-ı seb'a ve ilal kaideleri, mef'ile, mef'ûl YOK bâbları (F 360)
```
