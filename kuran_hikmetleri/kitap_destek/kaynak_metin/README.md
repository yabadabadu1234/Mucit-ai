# Münâsebet kaynak metinleri

Şâmile (shamela.ws) sayfalarından indirilip düz metne çevrilmiş dört kitap:

- `nazm_samela.txt` — Bikâî, Nazmü’d-Dürer (Şâmile kaynaklı Word dosyası; sayfa işaretleri "صفحة رقم")
- `burhan_samela.txt` — İbnü’z-Zübeyr, el-Burhân fî Tenâsübi Suveri’l-Kur’ân (Şâmile kitap 1388)
- `tenasuk_samela.txt` — Süyûtî, Tenâsuku’d-Dürer (Şâmile kitap 9992)
- `merasid_samela.txt` — Süyûtî, Merâsıdü’l-Metâli’ (Şâmile kitap 38158; kaynakta yalnızca 41 sayfa)

Her sayfa `[sayfa N · basılı M]` işaretiyle başlar. Metinler indirme betiğiyle üretilmiştir; el ile düzeltilmemiştir.
Telif: metinler kendi kaynaklarının (Şâmile ve tahkik sahipleri) malıdır; yalnızca araştırma amacıyla tutulur.
