## Nübüvvet

```
Nübüvvet ⊬ vâcip(Allah)           ∵ Fâil-i-Muhtar ; nübüvvet ihtiyârî ihsan
Mûcib(x) ⟹ irade(x) zâttan-çıkarılır ; Fâil-i-Muhtar(x) ⟹ irade(x) zâttan-çıkarılamaz
teşrî-irade(Vâcib) ⊄ eser(âlem)
∴ teşrî-irade bilinir ⟹ ihbar(Vâcib→insan)                        [burhânî]
Hakîm ∧ gaye(insan)=hür-fiil ⟹ gaye ihbar-edilmelidir             [gaye(insan)=hür-fiil ⊬ cedelî]
akıl ∧ öncül-doğrulama(bilinmez) ⟹ dışarıdan tashih               [empirik, hitâbî/cedelî]
```

## Mucize

```
Mucize(Rükün) = ⟨ harikuladelik, iddia, tahaddî, adem-i-muâraza, davaya-uygunluk ⟩   ⊬ Y-teklifi (beşli okunuş)
  ¬harikuladelik ∨ ¬iddia            ⟹ ≠ mucize
  harikuladelik ∧ ¬iddia             ⟹ kerâmet / irhâs
  iddia ∧ ¬(tahaddî ∧ adem-i-muâraza) ⟹ sihir/hile
  hepsi ∧ ¬davaya-uygunluk           ⟹ istidrâc

Mucize(çeşit) = { hissî, aklî }    κ = idrak-vasıtası(mucize)?   ⊬ Y-teklifi
  hissî : yalnız anında bulunana delil ; sonrakine HABER
  aklî  : her devirde yeniden sınanır

Hume:  "kanun = tecrübe ⟹ mucize ihtimali < yalan ihtimali"
  ⊬ ∵ kanun ≔ âdetullah (zıddı aklen mümkin)                     [imkân: burhânî]
  ⊬ ∵ döngü: bozulma-iddiasını baştan tecrübe-dışı saymak
  ⊬ ∵ tek-tanık için haklı ; çok-bağımsız-tanık için pⁿ küçülür  [⋉ Fasıl IV §1]
```

## Kur'ân'ın İ'câzı

```
Kaynak(Kur'ân) = { insan-Muhammed, başka-insan, ilâhî }     κ₁ = insan?  κ₂ = Muhammed?     [⟺ₜ Nakzeyn]
  ilâhî ≔ ¬κ₁ ; ispat = κ₁-kolunun elenmesi (kıyas-ı hulf)

Kol A — Tahaddî: [İsrâ 17:88 ▷ Hûd 11:13 ▷ Yûnus 10:38, Bakara 2:23 ▷ Tûr 52:34]  azalan talep
  H₁: tahaddî yapıldı [7. asır, Arapça, belâgat ehli, azamî imkân]                     [haber: burhânî]
  H₂: muâraza yerine çatışma seçildi ; benzeri getirilmedi                              [haber: burhânî]
  H₃: sonraki denemeler muâraza sayılmadı                                               [haber]
  Ö : insan sözü olsaydı muhalifler muâraza ederdi    ⊬ yakînî değil                    [çıkarım: cedelî-yüksek]
  ⊬ "kimse ebediyen yapamaz" — iddia edilmez (gelecek)

Kol B — Ümmîlik [Ankebût 29:48]: yazıyla öğrenmemiş ⟹ Şık-1 zayıf                     [haber: burhânî ; çıkarım: cedelî]
  itham-şekli "yardım aldı" [Nahl 16:103, Furkân 25:4-5]; cevap: a'cemî dil ⊬ sözlü nakli kapatmaz

Kol C — Nazm: Fesâhat ∧ Belâgat ∧ Talâkat (⊢ 41-meleke) ; ölçü = dil-ehliyeti           [cedelî-yüksek]
  çelişkisizlik [Nisâ 4:82]: ¬∃tenakuz — sınanabilir, olumsuz iddia                     [cedelî]

Toplam (A ∧ B ∧ C): ⊬ burhânî ; = cedelî-yüksek
  kapanmayan: sözlü nakil ; ölçülemeyen dehâ sınırı ; tesadüf (küçük, sıfır değil)
```
